# Zhike Novel（Skills 仓库）

本仓库存放以小说创作为目标的工作流技能。其核心思路是：以 **Agent 编排** 推动写作，以一组外部文档作为共同真相，使过程可推进、可回溯，并降低设定漂移与前后矛盾。


## 核心定位

- **Agent 驱动**：Agent 负责阶段推进，并自动创建/维护/更新全套外部文档；创作者负责意图输入、关键裁决与验收。
- **产物驱动**：设定/时间线/地图/大纲/细纲/正文/词条等文档构成唯一真相，避免信息散落。

## 设计要点

- **阶段化推进**：背景设定 → 大纲 → 细纲 → 正文；按需迭代，不追求一次性完备。
- **最小化原则**：只补“当前剧情需要”的设定与词条，避免过度设定锁死后续空间。
- **自动化资料维护**：角色/场景/势力等词条与设定文档由 Agent 按需增量更新（补齐缺口、同步变更、维护一致性）。
- **双向闭环**：正文引用资料库；新增要素反哺词条与设定文档；进度记录保证稳定续跑。
- **冲突显式化**：矛盾点收敛为待确认项，先确认再修改，减少隐性返工。

## 使用流程（Agent 编排）

1. **项目约束**：明确题材、受众、基调、禁区与目标情绪；Agent 自动沉淀为可长期引用的项目说明。
2. **背景设定**：Agent 自动建立 Setting / Timeline / map 的最小可用骨架，并自动初始化角色/场景/势力等词条库。
3. **大纲**：抽取主线与关键转折，确定全局节奏与章节功能。
4. **细纲**：设计单章体验与出场要素；Agent 自动将新要素同步沉淀到词条/设定。
5. **正文**：在资料库支撑下写作；发现缺口由 Agent 先补资料库再回正文；会话末自动更新进度与待确认项。

## 主要产物（Agent自动长期维护）

- `Setting.md`、`Timeline.md`、`map.md`
- `outline.md`
- `细纲/`、`正文/`
- `词条/`（角色/场景/势力/其他要素资料库）
- `项目状态记录.md`（阶段、任务、最近更新、待确认点）
